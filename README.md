GLOWTIDE — a 2D bioluminescent deep-sea arena survival game. You are a little firefly boat at 2,000 metres, fighting waves of glowing abyss creatures with light. Survive the waves, collect lumen, pick one of three upgrades after each wave, and chase the high score. Pure Canvas 2D + synthesized WebAudio, no libraries, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080
